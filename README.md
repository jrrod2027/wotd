# Vocabulario del Barrio

Static **word of the day** site for GitHub Pages.

Open the site → **today’s word** (or the most recent day on or before today). Future dates are never shown. Use ← / → to walk earlier and later published days.

## Day-to-day workflow

1. Create or edit `words/YYYYMMDD/` (example: `20261124` = Nov 24, 2026).
2. Commit and push to `main`.

That’s it. A GitHub Action rebuilds `data/manifest.json` for you. After Pages refreshes, the new day shows up.

You do **not** need to run any build command locally.

## Layout

| Path | Role |
|------|------|
| `words/` | **All content you edit** — one folder per day |
| `engine/` | Site UI (CSS + JS). Leave alone day-to-day |
| `index.html` | Page shell |
| `assets/flags/` | Official PR / DR flag SVGs |
| `scripts/build.mjs` | Used by CI only — scans `words/` → `data/manifest.json` |
| `data/manifest.json` | Generated by CI. Do not hand-edit |

### Day folder shape

```
words/20261009/
  word.txt              ← Spanish word (required)
  phonetic.txt          ← pronunciation spelling → shown as (koo-CHEE-yo)
  PR.wav                ← any audio file = a playable pronunciation
  DR.wav
  1/                    ← definition #1
    definition.txt      ← English gloss
    connotation.txt     ← theme → shown as (trauma)
    knife.png           ← any image = illustration for this sense
    kitchen.png
    example-cooking.txt ← line 1 Spanish, line 2 English
    example-street.txt
  2/                    ← definition #2
    …
```

**Rules**

- `word.txt` / `phonetic.txt` at the day root
- Audio extensions: `.wav` `.mp3` `.flac` `.ogg` `.m4a` `.aac` `.webm` `.opus` — button label comes from the filename
- Numbered folders `1`, `2`, … = definitions (order by number)
- Inside a definition folder: `definition.txt`, `connotation.txt`, image files, and **any other** `.txt` = example sentences (ES then EN)
- `.heic` / `.heif` are kept in the tree but skipped in the browser (prefer `.jpg` / `.png`)

See **`words/20261009/`** (`cuchillo`) for a full worked example.

## GitHub Pages

**Settings → Pages → Deploy from a branch** → `main` / `(root)`.

## Local preview (optional)

```bash
# only needed if you want to preview before the Action runs
node scripts/build.mjs
python3 -m http.server 8080
```

## Notes

- **“Today”** uses the visitor’s local calendar date.
- Days without `word.txt` are skipped.
- ← / → jump to the previous/next *published* day, not empty calendar days.
